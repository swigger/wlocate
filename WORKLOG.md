## Fix — actual file icons and full-path cache, 2026-10-07

- User observed that all three `Figma.exe` results stayed generic even when left idle. Confirmed in the installed UI. Previous async implementation only requested generic extension icons (`file.exe` with SHGFI_USEFILEATTRIBUTES); it never requested actual executable resources, so waiting could not change them. This was an incomplete follow-up load, not a missing repaint notification.
- `AsyncIcons` now has two layers: generic type icons provide the immediate fallback; the same dedicated COM worker loads actual file icons using the complete indexed path without SHGFI_USEFILEATTRIBUTES. Completion posts to the existing GUI handler and repaints automatically. File/path lookups remain off the GUI and search threads.

Modification/creation timestamps, size and attributes invalidate a file entry; revision numbers reject outdated completions. Failed loads retain the generic fallback and retry after five seconds instead of poisoning the cache permanently or retrying every paint.
- Added 16 icon-cache checks covering fallback-to-file replacement, identical basename/extension in different directories, reuse, metadata invalidation, stale completion rejection, failure throttling/recovery, bounded eviction, and a real embedded EXE icon. ## Objective

Build an independent native Windows file finder, referring to SwiftList's indexing/service design and Everything's observable behavior. Deliver `wlocate.exe` (GUI and Windows-service modes) and `locate.exe` (command line). Keep existing Everything and SwiftList operational during development. Use `psuac -w -o <log> ...` for authorized administrative deployment and diagnostics.

## Acceptance

- Index all mounted local NTFS volumes, including every hard-link name, using MFT metadata; persist snapshots and replay USN changes after restart.
- Apply create, rename, move, delete and hard-link changes without a full rescan; detect journal gaps and rebuild safely.
- Search in the service, return only final matches, and stop limited CLI queries promptly.
- Native GUI with incremental search, virtual result list, common filters/syntax, sorting, standard keyboard actions and real Windows Shell context menus.
- CLI supports the prior locate-style options, UTF-8 and NUL output, clear exit codes and errors.
- Compare result sets and latency to the installed Everything-based `locate.old.exe`, including hard links and live-update fixtures.
- Exercise GUI, service restart/cache recovery and command replacement; retain rollback copies.
- Document implemented functions, measured performance, and remaining differences from Everything honestly.
